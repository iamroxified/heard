# Heard In Africa — Agent Rules

## Git & GitHub

- **Always push to GitHub after every change.** After completing any code modification, run:
  ```
  git add -A
  git commit -m "<type>: <concise description of what changed>"
  git push origin main
  ```
- Use conventional commit prefixes: `fix:`, `feat:`, `chore:`, `refactor:`, `style:`, `docs:`
- Write clear, descriptive commit messages that explain *why*, not just *what*.
- In PowerShell, use `;` as the command separator (not `&&`).
